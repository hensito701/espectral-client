# ruta-relay

Ruta Espectral's MVP-only Minecraft TCP relay. Build, flags and deploy steps:
[`deploy/README.md`](deploy/README.md). Wire contract: [`PROTOCOL.md`](PROTOCOL.md).

Quick start (WSL):

```bash
~/.cargo/bin/cargo test --offline
~/.cargo/bin/cargo build --release --target x86_64-unknown-linux-musl
```
